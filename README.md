# Bowen Zhang — Academic Homepage

Live website: https://bowen-buct.github.io/

This repository contains Bowen Zhang's English academic homepage, including research interests, publications, projects, academic background, awards, and contact information.

## Updating the website

The site is contained in `index.html`, including its styles and publication year filter. On GitHub, open `index.html`, choose Edit, update the relevant text, and commit the change to `main`. GitHub Pages will publish the update automatically.

Publication years and bibliographic details follow the final journal volume and issue. The list currently contains 15 papers, including the 2026 coal railway transport systems paper. DOI links are included where verified.

## Hosting

GitHub Pages publishes the `main` branch from the repository root. The `.nojekyll` file serves the site directly as static HTML. The legacy `_config.yml` is not used by the website.
